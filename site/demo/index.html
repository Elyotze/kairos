    Présence et capacité

    Cliquez une case pour changer le statut d'un opérateur (présent, absent, congé, formation, prêt à une autre ligne), puis recalculez. Les jours passés sont figés.

    Matrice de compétences

    Niveau 1 : en formation (durée × 1,30) · niveau 2 : confirmé (× 1,00) · niveau 3 : expert (× 0,85). Le contrôle final exige le niveau 2.

    Gamme type (20 opérations par OF)

    Durées standard avant prédiction. Liens : FS fin → début, SS début → début avec décalage, FF fin → fin.

    Flux de bout en bout

    1. Extraction planifiée : ERP (API OData standard), MES, plateforme data en option.
    2. Données brutes en staging, puis upsert idempotent vers les tables propres.
    3. Saisie des présences et compétences via l'API.
    4. Le Gantt demande un calcul.
    5. L'API dépose la tâche dans la file et répond aussitôt.
    6. Le worker lit l'état consolidé en base.
    7. Le solveur résout et écrit le planning, avec les durées prédites.
    8. Le worker notifie l'API.
    9. Push WebSocket : le Gantt se met à jour.
